# Parse Intent

You are parsing a user's free-text request for planning a night out in NYC.

## Goal
Extract structured intent from the user's request: area, time window, budget, dietary needs, vibe tags, and the sequence of stop types they want (e.g., drinks → dinner → dessert).

## Input
- **Free text request:** The user's description of what they want (may include constraints, preferences, vibes, timing, location)
- **Optional structured fields:** date/time, budget, neighborhood (these override the free text if provided)

## Output Schema
Return a JSON object matching the `intentSchema`:
```json
{
  "area": "string (1-120 chars, e.g., 'Union Square', 'Lower East Side', 'Manhattan')",
  "window": {
    "start": "ISO datetime string",
    "end": "ISO datetime string"
  },
  "budgetUsd": "positive integer, max 100000",
  "dietary": ["array of dietary restrictions, max 8, each 1-40 chars"],
  "vibeTags": ["array of vibe/mood tags, max 8, each 1-40 chars"],
  "stopTypes": ["array of 2-4 stop types from: drinks, dinner, dessert, bar, lounge, cafe, activity"]
}
```

## Rules
1. **Area:** Extract neighborhood, area, or borough. Default to "Manhattan" if not specified.
2. **Time window:** Parse timing clues ("after 7", "evening", "late night"). If only a start is given, assume a 4-hour window. Use the provided date or default to the current Friday evening if not specified.
3. **Budget:** Extract total budget for the night. If per-person is mentioned, multiply by 2 (couples v1). Default to $150 if not specified.
4. **Dietary:** Extract any dietary restrictions or preferences (vegetarian, vegan, gluten-free, etc.). Empty array if none mentioned.
5. **Vibe tags:** Extract mood, atmosphere, or style preferences (romantic, low-key, special, trendy, cozy, upscale, casual, etc.). Max 8 tags.
6. **Stop types:** Infer the sequence of venue types. Common patterns: drinks → dinner → dessert, dinner → drinks → bar. Must have 2-4 stops.

## Examples

**Input:** "Low-key but special dinner near Union Square after 7, she's vegetarian"
**Output:**
```json
{
  "area": "Union Square",
  "window": {
    "start": "2026-10-10T19:00:00Z",
    "end": "2026-10-10T23:00:00Z"
  },
  "budgetUsd": 150,
  "dietary": ["vegetarian"],
  "vibeTags": ["low-key", "special"],
  "stopTypes": ["dinner"]
}
```

**Input:** "Date night in Brooklyn, drinks then dinner, we like cocktails and good vibes, around $200 total"
**Output:**
```json
{
  "area": "Brooklyn",
  "window": {
    "start": "2026-10-11T18:00:00Z",
    "end": "2026-10-11T23:00:00Z"
  },
  "budgetUsd": 200,
  "dietary": [],
  "vibeTags": ["good vibes", "cocktails"],
  "stopTypes": ["drinks", "dinner"]
}
```

## Instructions
- Be conservative with assumptions
- Preserve the user's intent and constraints
- Default to couple-friendly venues (v1 scope)
- Window end must be after window start
- Stop types must be in the intended chronological order
