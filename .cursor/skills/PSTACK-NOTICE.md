# Vendored pstack Skills

This directory contains skills vendored from the [pstack plugin](https://github.com/cursor/plugins/tree/main/pstack/skills) version v0.15.15.

## Source

- Repository: https://github.com/cursor/plugins
- Path: pstack/skills
- Version: v0.15.15
- License: MIT (see PSTACK-LICENSE)

## Vendored Skills

The following skills have been copied byte-for-byte with no modifications:

- **architect** - Sketch types/signatures/module structure before non-trivial code
- **tdd** - Test-first development for new behavior and bug fixes
- **blast-radius** - Check what a change could break beyond the diff before shipping
- **maintain-verification-skill** - Keep verification skills current when app behavior changes
- **typescript-best-practices** - TypeScript patterns and types for this codebase
