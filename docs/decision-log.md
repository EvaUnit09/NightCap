| 25 | 2026-10-10 | **ACCEPTED** (owner decision, Noah): NightCap v1 travel modes are TRANSIT (subway/train), BICYCLE, and WALK only. Rideshare, DRIVE, and taxi are out of scope; the validator fails those closed as `travel_unverified`. Travel minutes come from Google Routes `computeRouteMatrix` (POST https://routes.googleapis.com/distanceMatrix/v2:computeRouteMatrix), Essentials tier, field mask `originIndex,destinationIndex,duration,condition,status`. Auth is the existing `GOOGLE_PLACES_API_KEY` via `X-Goog-Api-Key`. Billing is per element (`origins × destinations`); each consecutive hop is one 1×1 matrix (never N×N). A request has one `travelMode`, so mixed-mode nights are one 1×1 call per hop. `departureTime` (the originating stop's end) is sent for TRANSIT only. Haversine is a test/offline fallback only. Cap check is `max(claimed, computed)`. Fail closed when travel cannot be computed. Cost basis: `budgetUsd` is the party's total for the night (a couple by default). `estimatedCostUsd` is each stop's total for the whole party. The validator sums stop totals against `budgetUsd`. `PRICE_LEVEL_*` heuristic ranges stay per person and are compared to `estimatedCostUsd / partySize` (default 2). `PRICE_LEVEL_UNSPECIFIED` skips. | (1) Haversine × circuity ÷ modal speed (zero cost; kept as offline fallback). (2) Legacy Distance Matrix API: Legacy as of 2025-03-01; not available on new Cloud projects ([Legacy products](https://developers.google.com/maps/legacy)). (3) Include DRIVE / rideshare / taxi (owner rejected for v1). | Owner decision. Essentials SKU 9392-1087-2045 is $5.00 / 1,000 elements after a 10,000-element monthly free cap ($0.005/element paid). Source: [Maps Platform price list](https://developers.google.com/maps/billing-and-pricing/pricing). Docs check (2026-10-10): `computeRouteMatrix.travelMode` is `RouteTravelMode`, which includes WALK, BICYCLE, and TRANSIT ([RouteTravelMode](https://developers.google.com/maps/documentation/routes/reference/rest/v2/RouteTravelMode); [computeRouteMatrix](https://developers.google.com/maps/documentation/routes/reference/rest/v2/TopLevel/computeRouteMatrix)). TRANSIT on the matrix endpoint: [Get a route matrix on transit](https://developers.google.com/maps/documentation/routes/transit-rm). Caveats: (a) WALK and BICYCLE are beta and may miss sidewalks or bike paths; Google requires displaying that warning. (b) TRANSIT is limited to 100 elements per request; 1×1 stays at 1. (c) One `travelMode` per request — modes cannot be mixed in one matrix. (d) `routingPreference` is only valid for DRIVE / TWO_WHEELER and would fail WALK / BICYCLE / TRANSIT, so it is never sent. (e) `departureTime` is optional and defaults to now; a past `departureTime` is allowed only for TRANSIT; `arrivalTime` is TRANSIT-only. (f) TRANSIT is available where public transit exists; NYC subway/train/bus is in scope. Cost (see #28): each validation bills at most 4 Routes elements. Paid Routes Essentials: $5.00 / 1,000 elements after 10,000 free/month = $0.005/element. 2×$0.005=$0.010; 3×$0.005=$0.015; 4×$0.005=$0.020 (cap). Per-validation Routes ≤ $0.020. Places: candidate fields (rating, priceLevel, openingHours, reviewCount) bill Places Text Search Enterprise at $35.00 / 1,000 after 1,000 free/month = $0.035/request, not Text Search Pro. #3 caches only place_id and coords, so those Enterprise fields are not reused and every plan pays the search again. A typical first-pass night has 2 stop types → 2 Text Search Enterprise calls = 2 × $0.035 = $0.070. Labeled per-request stages: parse (Haiku 4.5, small vs plan); Places Text Search Enterprise $0.070 (2 × $0.035); plan (Sonnet 5) ~$0.03 (scope.md); Routes $0.010–$0.020 typical (2–4 hops; preferred 3×2 = 3 hops / 2×3 = 4 hops). Typical first-pass subtotal: $0.03 plan + $0.015 Routes + $0.070 Places = $0.115, plus parse. That is over scope.md's under-$0.05 target; flagged to Noah — the $0.05 target is unchanged pending that decision. The old ~$0.040 figure was Routes+plan only; the prior $0.077 used Pro $0.032 and treated details as cached. Repair ≤ 2 rounds: each re-validates (≤ 4 more elements, $0.020) plus a Sonnet repair call (~$0.03); repair does not re-search Places when it reuses candidates. Worst Routes on one request: 3 validations × 4 elements = 12 × $0.005 = $0.060. Agent turns are a separate $0.03/turn cap. Identical legs are memoized within one validation call only (no cross-request cache), to stay inside Google's caching terms. |
